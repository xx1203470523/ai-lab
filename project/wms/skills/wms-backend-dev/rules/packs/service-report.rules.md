# Service Report Rule Pack

适用场景：

- 报表新增
- 报表优化
- 报表分页查询
- 报表导出
- MiniExcel
- 大数据量查询
- 查询防刷
- 报表 DTO 调整

# 1. Report Boundary

- 报表修改必须绑定明确报表、入口和业务目标。
- 禁止一次性批量修改多个无关报表。
- 必须保护：
  - 字段含义
  - 查询条件语义
  - 排序语义
  - 导出业务含义

以下变化属于契约风险：

- 字段删除
- 字段重命名
- 字段类型变化
- 导出列变化
- DTO 结构变化

未经确认禁止修改。

# 2. Query Safety

报表查询必须避免无保护的大范围查询。

约束：

- 大数据量报表必须存在有效查询条件。
- 禁止默认无条件查询大表。
- 无时间条件时，应根据业务增加默认时间范围或限制。
- 默认时间范围应设计为使预估数据量不超过 10w。
- 时间范围限制前后端均需校验：后端抛异常，前端禁用导出按钮 + 提示。

高选择性条件优先：

- 单号
- 标签号
- 批号
- 物料编码
- 状态
- 时间范围

弱条件：

- 名称
- 备注
- 描述

不得单独作为大数据量查询入口。

# 3. String Query

禁止：

- 全模糊查询
- `%keyword%`
- 无限制 Contains 查询

字符串查询：

- 编码类字段优先等值查询。
- 时间字段使用范围查询。
- 集合查询需要控制集合规模。

# 4. ID Prequery

ID 预查询仅适用于小结果集。

适用：

- 用户
- 字典
- 仓库
- 项目
- 小规模维度过滤

禁止：

- 大明细表先查大量 ID 再 Contains。

大结果集跨表过滤：

- 使用 EXISTS / 子查询方案。

# 5. Paging Query

分页查询必须关注：

- 查询条件
- Count 成本
- JOIN 数量
- 补充字段范围

约束：

- 分页补充数据只能针对当前页数据。
- 禁止分页后查询全量关联数据。
- 高风险报表禁止直接无保护 ToPageAsync。

# 6. Export Query

导出必须：

- 使用项目统一 Excel 方案。
- 使用独立 ExportDto。
- 与分页共用同一查询构建器（最小 JOIN，时间条件兜底）。
- 同用户导出操作未完成前禁止重复发起（`ICachingService.LockAsync` + 用户 ID 锁）。

禁止：

- 先全量 ToList 再判断数量。
- 无限制加载大量数据。
- 分页和导出各写查询构建器。

导出必须考虑：

- 数据量限制
- 内存风险
- 重复导出
- 并发导出
- 分批游标取数（CreateOn + Id 复合游标，禁止 OFFSET）

# 7. Read Replica（后续规划）

- 报表 SELECT 查询走从库数据源。
- 从库连接串独立配置。
- 当前未实现，新增报表预留切换点。

# 8. DTO Contract

报表 DTO 默认：

- QueryDto：查询条件
- PagedQueryDto：分页查询
- Dto：展示数据
- ExportDto：导出结构

禁止：

- 用展示 DTO 直接作为导出 DTO。
- 未确认修改 API 返回字段。
- 未确认修改导出列。

# 9. Performance Boundary

允许：

- 表结构查看
- 索引查看
- Explain
- 小范围查询验证

禁止：

- 全表扫描验证。
- 无条件查询。
- 无限制导出。
- 影响生产的大范围测试。

数据库验证结果必须说明：

- 查询条件
- 数据范围
- limit
- 风险。

# 10. Concurrency Protection

高成本报表需要考虑：

- 重复点击
- 重复导出
- 同用户并发

可采用：

- 防抖
- TTL 锁
- 导出锁
- 异步任务

限制必须返回明确业务提示。

# 11. Verification

报表修改后至少验证：

- 正常查询
- 无条件查询限制
- 分页结果
- 导出限制
- 字段兼容性

完成后检查：

- 无用 using
- 无用字段
- 无用方法
- 调试代码
- 临时代码
