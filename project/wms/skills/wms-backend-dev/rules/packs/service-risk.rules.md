# Service Risk Rule Pack

命中条件：任务涉及状态切换、库存、标签、质检、T100、立库或远程调用。

## State Switching

- 状态变更必须有明确前置状态、目标状态和失败分支。
- 库存、标签、质检、调拨、T100、立库等高风险状态流不得靠猜测补逻辑。

## Inventory / Labels / T100 / 立库

- 涉及库存变更时，必须确认库存流方向、数量、批次、库位和状态影响。
- 涉及标签变更时，必须确认标签规则、标签状态和标签触发条件。
- T100、立库、外部 HTTP 调用默认不放在数据库事务中。

## Remote Calls

- Service 调用远程系统必须明确失败处理、状态记录和重试或人工处理边界。
- Service 修改实体字段语义时必须确认实体规则和数据库影响。
- 禁止在事务中放入远程调用。
