## 提效比控制速查

| 场景 | 原始提效比 | 调整方式 | 目标区间 |
|------|-----------|---------|---------|
| 提效过高 | > 40% | 保持预计工时，上调实际工时 | 25%~35% |
| 提效为负 | < 0% | 保持原始工时事实，风险/备注说明 | 0%~10% |
| 正常偏高 | 30%~40% | 不调整或少量上调实际工时 | 保持或微调至 25%~35% |
| 正常范围 | 10%~30% | 不调整 | 保持原值 |
| 正常偏低 | 0%~10% | 不调整 | 保持原值 |
| 日志缺失预计工时 | 无 | 写 `未记录`，不反推 | 不计算或按规则说明 |

约束：

- 不承载输出强约束；强约束必须进入 `../rules/business/work-summary.rules.md`。
- 示例不允许覆盖日志事实来源。
- 与 Rules 冲突时，以 Rules 为准。
