## 使用方式

1. 在 Skill 中引用：`先 search-knowledge.ps1 -Keyword "入库" 检索相关知识`
2. 命中：读取对应文件
3. 未命中：跳过（零 token 成本）

## 维护约定

### 谁来维护

- 通过 `knowledge-manage` skill 管理（`@../skills/knowledge-manage/SKILL.md`）
- 排查完一个领域逻辑、确认代码事实后，沉淀为知识文件

### 文件格式

- 标题简洁描述主题
- 首行 `> 最后更新: YYYY-MM-DD` + `> 来源：一句话场景`
- 内容用表格承载映射/决策，代码引用用路径+行号（不贴完整代码）
- 必须包含"关键代码位置"表，用于日后验证知识是否过期
- 只写从代码确认的事实，禁止推测

### 索引更新

- 新增文件后**必须**更新本索引
- 关键词中英混合、覆盖常见别名
- 文件不存在时标记 `(待建)`，待建条目不占 token
- 删除/重命名文件时同步清理索引行

### 目录约束

- 一个文件只归属一个目录（`backend/` / `frontend/` / `pda/`）
- 按领域命名：`<主题-kebab-case>.md`
- 禁止跨域混合（如 PDA 知识写在 backend/ 下）
