# 技能命名规范

## 工具型

`<name>` — 简短名词或动词短语；多词用 `-` 连接。

- `git`
- `task-plan`
- `task-execute`
- `skill-gen`

## 业务型

`<business>-<module>` — 业务名 + 模块名。

- `wms-backend-dev` — WMS 后端开发
- `wms-pda-dev` — WMS PDA 端
- `wms-publish` — WMS 发布
- `trade-watch` — 炒股监控

## 约束

- 全小写
- 英文命名
- 分隔符统一用 `-`
- 不超过 3 段（`a-b-c` 是上限）
