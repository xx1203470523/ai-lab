# 技能命名规范

## 工具型

`<name>` — 简短动词/名词，无连字符

- `git` — 版本控制
- `task-plan` — 任务规划（多词用 `-` 连接）
- `task-execute` — 任务执行

## 业务型

`<business>-<module>` — 业务名 + 模块名

- `wms-backend-dev` — WMS 后端开发
- `wms-pda` — WMS PDA 端
- `wms-publish` — WMS 发布
- `trade-watch` — 炒股监控

## 约束

- 全小写
- 英文命名
- 分隔符统一用 `-`
- 不超过 3 段（`a-b-c` 是上限）
