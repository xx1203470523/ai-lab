# Git Worktree 规范

**执行方式**：创建走 `../scripts/wt.ps1 -Action create|attach`，清理走 `../scripts/cleanup.ps1`。
阻断条件、令牌算法、错误码以 `../reference/scripts/script-contract.md` 为准，本文件不复述实现。

## 创建规范

- 工作区目录统一放在项目根目录下的 `.claude/worktree/` 中
- 工作区命名用 `-` 分隔，分支命名用 `/` 分隔
- 禁止创建与已有工作区同名的分支
- 禁止在任何 worktree 目录内创建新的 worktree
- 基分支必须**解析**出来，不许猜；有多个远端候选且用户没指定时，停下来问

## 删除规范

- 未经用户确认不得删除任何代码或工作区
- 代码改动只限于工作区内
- 禁止删除有未合并代码的工作区
- 禁止删除有未提交改动的工作区
- 合并状态**无法确认**（脚本判定 `unknown`）时按「不可删」处理，把不确定告诉用户
- 清理必须两阶段：先 `plan` 展示真实清单，取得用户确认，再带令牌 `apply`；
  禁止跳过预检直接执行，禁止手工编造令牌
