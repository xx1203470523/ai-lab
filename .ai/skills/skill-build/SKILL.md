# Skill Build

## 1. 目标类型

用于生成或优化"Core Skill"。

优化加载

Tools Skill 定义：
- 纯功能型技能（如 git、文件处理、环境操作）
- 描述可执行流程
- 不包含业务逻辑（如电商、金融、库存规则）

## 2. 触发方式

- `/skill-core-build 生成 <功能描述>`
- `/skill-core-build 优化 <skill名>`
- 用户描述：新建 skill、优化 skill、写一个 git / 文件 / 工具类操作
